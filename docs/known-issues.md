# Known Issues

Latent issues and small cleanups, documented so they can be picked at a future date.

## Small-sized issues

1. **Clamp is one-directional**: raising a duration mid-session does not rescale upward, and an idle timer at full duration does not follow a raised setting. Locked in by the test `does not rescale the remaining time upward when the phase duration grows`. Revisit only if proportional rescale (or idle-follows-setting) is the wanted UX.
2. **Same-day restore advances at most one phase**: a running timer restored after more than one full phase elapsed moves to the next phase idle and discards the remaining elapsed time. Defensible (avoids silently racking up completions); revisit if multi-phase catch-up matters. Cross-day snapshots are discarded instead of advanced.
3. **A running timer is reset at the day boundary**: the rollover reset starts a fresh work phase even if a session is actively running at the reset hour. This is intentional so the first view of a new day is always the focused work phase. Revisit if preserving a late-night in-progress session matters more.
4. **Day rollover can lag by one poll interval**: the render path is kept pure (no clock read during render), so the reset happens on the 30s poll or on the next focus/visibility event. The UI can lag briefly after the boundary; a work phase that completes within that window increments the previous day's count before the reset zeroes it. The persisted snapshot can also carry the stale day until the next persist (`restoreTimerState` discards stale-day snapshots on load, so there is no data loss).
5. **Version module can drift**: `src/version.mjs` is generated by genversion and committed. Editing `package.json` without running `npm version` leaves it stale, and nothing currently checks it. Consider adding `genversion -c -des src/version.mjs` to CI/preflight if this becomes a problem.
6. **Background throttling needs macOS 14**: `backgroundThrottling: "disabled"` in `src-tauri/tauri.conf.json` only works on macOS 14 or later. On older versions, a hidden menu-bar window can still play the phase-end sound and notification late, although the display catches up when the window is shown.
