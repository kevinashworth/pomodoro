# App Menu

## What it does

A desktop menu bar.

- **Pomodoro**
  - Settings… `⌘,`
  - Quit `⌘Q`
- **View**
  - Go to Timer `⌘1`
  - Toggle Mini Mode `⌘⇧M`
  - Enter Full Screen `⌘⇧F`

In the browser, the keyboard shortcuts of these items trigger the same actions. Every command works on desktop and in a plain browser.

## Architecture

- **Rust**: `menu.rs`, `menu_actions.rs`, wired in `lib.rs`
- **React**: constants, hooks
- **Routing**: turns commands into navigation: e.g., Settings navigates to the settings page, and Escape backs out
- **Settings**: moved to a new React context, and a new settings page replaces the settings dialog
